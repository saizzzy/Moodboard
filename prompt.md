Роль: Senior Frontend-Designer / UI Architect. 
Задача: Написать архитектуру компонентов и интерфейс для образовательного VK Mini App на базе библиотеки VK UI, React. 

Ограничения:
1. Запрещено затрагивать бэкенд, писать логику серверов, базы данных или API-эндпоинтов (вся работа только с фронтендом и UI). 
2. Запрещено использовать сложные абстракции, переусложненные архитектурные паттерны и лишний оверинжиниринг. Код и структура должны быть простыми и понятными.
3. Запрещено использовать библиотеки и зависимости, которые нельзя применять в коммерческой разработке (строго свободные лицензии вроде MIT, Apache 2.0). 
4. Коментировать код строго по блокам и обьяснять их, показывая коментариями начало и конец каждого логического блока.
Функциональные требования:
5. Шапка: Название приложения слева, кнопка настроек (шестеренка) справа. При клике открывается модальное окно с переключателем темной/светлой темы.
6. Нижняя панель навигации: Фиксированный таб-бар с тремя кнопками: «Расписание», «Оценки», «Профиль».
7. Экран «Расписание»: 
   - Список уроков.
   - У каждого урока есть автоматическая кнопка поиска учебных материалов по теме. При клике на нее блок расширяется с плавной анимацией, не ломая мобильную сетку, а элементы управления сохраняют видимость.
4. Экран «Оценки»: 
   - Сетка компактных карточек. Каждая карточка содержит: оценку, дату и название предмета.
   - Блок с общим средним баллом.
   - Текстовый блок с аналитикой динамики оценок.

Что нужно предоставить:
- Иерархию React-компонентов с использованием VK UI.
- Описание структуры сетки и адаптивности под мобильные клиенты VK.
- Принципы плавных переходов (анимации) при разворачивании блоков с контентом.
